# Библиотека знаний Authentic Tantra

Это внутренний интеллектуальный фундамент бренда. Он не для внешней публикации. Он для того, чтобы каждый будущий урок, курс, ретрит, статья, пост, презентация и практика опирались на глубоко изученные, оригинально пересказанные идеи из первоисточников — а не на пересказы пересказов.

## Как устроена библиотека

```
library/
├── README.md                    ← этот файл
├── knowledge_base.md            ← центральный кросс-референсный индекс идей
└── books/
    ├── 01_marciniak_bringers_of_the_dawn.md
    ├── 02_dillon_tantra_path_to_bliss.md
    ├── 03_jewel_in_the_lotus.md
    └── ... (следующие книги добавляются по мере поступления)
```

## Правило работы с библиотекой

**Никогда не копируем текст источников.** Извлекаем идеи, принципы, концепции, техники — своими словами, с сохранением авторского смысла.

**Всегда указываем источник.** Каждая идея в базе знаний помечена, из какой книги она пришла. Если одна и та же идея встречается у нескольких авторов — фиксируем совпадение. Если авторы расходятся — фиксируем различие.

**Никогда не смешиваем авторов без нужды.** Каждый источник имеет свою внутреннюю логику. Мы её уважаем.

**Никогда не выдаём чужую уникальную формулировку за свою.** Если идея явно принадлежит конкретному автору (напр., "Iyari" Пемы Гитамы) — мы используем её как принцип, а не как маркетинговый лозунг бренда.

## Структура анализа каждой книги

Каждый файл в `/books/` содержит 8 разделов:

1. **Главные идеи** — 20–50 фундаментальных мыслей, своими словами
2. **Карта понятий** — как ключевые концепции связаны между собой
3. **Принципы** — что автор считает фундаментальным, что повторяется
4. **Практическая ценность** — где идеи работают в жизни/теле/отношениях
5. **Практики** — конкретные упражнения, техники, медитации (суть, цель, эффект, сложность, контекст)
6. **Язык автора** — как строит объяснение, какие метафоры, как удерживает внимание
7. **Что ценно для Authentic Tantra** — фильтр через бренд: что берём, что переосмысливаем, что не подходит
8. **Ссылка в базу знаний** — какие идеи попали в `knowledge_base.md` и под какими тегами

## Как использовать библиотеку при создании нового материала

**Перед созданием урока/курса/ретрита:**
1. Открой `knowledge_base.md`
2. Найди релевантные тематические разделы
3. Посмотри, какие идеи из каких книг там собраны
4. Прочти соответствующие разделы в файлах книг для контекста
5. Синтезируй оригинальный материал — не пересказ отдельной книги

**Флаг качества:** если новый материал звучит как краткая версия какой-то одной книги — это ошибка. Мы должны опираться на несколько источников одновременно + собственную методологию бренда + философию Пемы, чтобы получить оригинальный синтез.

## Собственные источники бренда (не в этой библиотеке)

Не смешиваются с внешними книгами:
- `/strategy/methodology_authentic_tantra.md` — наша методология
- `/strategy/pema_gitama_source_of_truth.md` — Source of Truth Пемы (охраняется как основа лини)
- `/strategy/visual_dna_authentic_tantra.md` — визуальный код
- `/brand/*.md` — идентичность, голос, миссия

## Логика роста

Библиотека дополняется постепенно. Каждая новая книга проходит те же 8 разделов, затем интегрируется в `knowledge_base.md`. По мере роста будут появляться:
- **тематические индексы** (напр., «Все идеи о теле», «Все идеи о тишине»)
- **карты противоречий** (где источники расходятся — важно знать)
- **выделенные концепции** (когда одна и та же идея встречается у 3+ авторов — становится «общим слоем»)

## Порядок ввода новых материалов

1. Извлечь текст из книги/PDF
2. Провести 8-разделный анализ → сохранить в `/books/NN_author_title.md`
3. Обновить `knowledge_base.md` — добавить новые идеи, отметить пересечения и различия
4. Только после этого — начинать создавать любые новые уроки / посты / курсы
