## Правила работы с базой

**Никогда не удалять.** Только архивировать с пометкой причины.

**Никогда не выдумывать.** Только систематизировать то, что передано или подтверждено источником.

**Всегда указывать источник.** Каждая практика, принцип, идея имеет ссылку на происхождение.

**Открыто фиксировать противоречия.** Не выбирать одну точку зрения. Показывать обе.

**Одна карточка на одну сущность.** Разные адаптации — разделы внутри одной карточки.
