# Archive · Устаревшие агенты AI-команды

Эта папка содержит агентов, созданных в апреле-мае 2026, которые были **superseded** (заменены) новыми Skills в июле 2026.

**Правило:** файлы в этой папке НЕ должны активироваться в новых сессиях. Они сохранены только для истории и справки. Если Клод в новой сессии случайно активирует что-то отсюда — это ошибка.

**30 июля 2026:** Виктория запросила создание полной интеллектуальной системы. Построены 5 новых Skills:
1. AI Executive Director
2. Audience Psychology Researcher
3. Content & Conversion Architect
4. Knowledge Core & Practice Curator
5. Brand Guardian (элевирован из существующего)

**30 июля 2026 (тот же день):** проведён независимый аудит системы. Ключевая рекомендация — консолидировать legacy-агенты в архив, чтобы не создавать путаницу.

**30 июля 2026:** 5 legacy-агентов перемещены в этот `_archive/`.
