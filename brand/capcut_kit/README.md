## Сборка мастер-шаблона в CapCut Web (10 минут)

### Шаг 1 · Открыть проект (30 сек)
1. Открой **capcut.com** → войди в аккаунт
2. **Create project** → размер **9:16 Portrait**

### Шаг 2 · Сохранить бренд-цвета (2 мин)
1. Добавь любой текст → открой colour picker
2. В строке **Custom** нажми `+`
3. Введи по очереди все 4 HEX-кода из `04_palette_card.png`:
   - `2B2A28` Charcoal
   - `F2EADF` Cream Alba
   - `FBF8F2` Off-white
   - `A68A5B` Brass
4. Save каждый

### Шаг 3 · Импорт intro + outro (1 мин)
1. Перетащи `01_intro_1080x1920.png` в timeline на позицию **00:00**
2. Обрежь до **1 секунды**
3. Перетащи `02_outro_1080x1920.png` в timeline после placeholder
4. Обрежь до **2 секунд**

### Шаг 4 · Placeholder для контента (30 сек)
1. Между intro и outro добавь любой цветной фон на 10 секунд
2. Назови его **DROP VIDEO HERE**

### Шаг 5 · Настроить subtitle style (5 мин)
Это самый важный шаг — экономит часы в будущем.

1. Добавь тестовый текст в timeline: `тест субтитра`
2. Настрой стиль строго по `03_subtitle_style_reference.png`:
   - Font: **Cormorant Garamond Regular** (в поиске набери «Cormorant»)
   - Size: **11–12pt**
   - Color: Cream Alba `F2EADF`
   - Stroke: **None**
   - Shadow: Y-offset 4, Blur 8, Black, Opacity 30%
   - Position: горизонтальный центр, ~75% сверху
3. Правой кнопкой на этом клипе → **Save as text preset**
4. Назови «**SHUNQU subtitle**»

### Шаг 6 · Сохранить как мастер-шаблон (30 сек)
1. Название проекта вверху слева — переименуй в:
   **🎨 SHUNQU MASTER TEMPLATE — do not edit**
2. Auto-save сохранит

## Использование для нового Reel

1. Открой мастер-шаблон
2. Три точки справа от названия → **Duplicate**
3. Переименуй копию (например `2026-07-27 · Reel · утро на веранде`)
4. **Открой копию** (не оригинал — оригинал не трогаем!)
5. Удали DROP VIDEO HERE placeholder → перетащи своё видео
6. **Auto-captions** → выделить все субтитры → применить **SHUNQU subtitle preset**
7. Добавь музыку (см. рекомендации в `/content/reels/` — там подобранные треки)
8. **Export**: 1080p, 30fps, High quality

## Экономия времени

**Без шаблона:** ~25 мин на каждый Reel (палитра, стили, интро, outro каждый раз с нуля)
**С шаблоном:** ~5 мин на каждый Reel (только замена контента + captions)
**За месяц (8 Reels):** экономия **2–3 часа + идеальная бренд-консистентность**

## Обновление шаблона

Если хочешь изменить intro/outro (например добавить новую соцсеть или изменить IG-хендл):
1. Обнови ассеты через меня — я перегенерирую PNG
2. Открой мастер-шаблон в CapCut
3. Удали старый intro/outro clip → перетащи новый
4. Сохрани

Все Reels, которые ты уже сделала, останутся с прежним intro. Только новые получат обновлённый.
