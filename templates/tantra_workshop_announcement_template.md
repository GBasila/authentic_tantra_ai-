# Шаблон Анонсов для Тантрических Воркшопов

Этот файл — эталон формата, утверждённый Викторией. Когда она просит «сделай анонс для воркшопа на такую-то тему», использую эту структуру и подставляю переменные блоки под тему занятия. Неизменные блоки сохраняю дословно.

---

## Структура шаблона

**Каждый анонс = 4 блока в строгом порядке:**

| # | Блок | Статус | Что содержит |
|---|---|---|---|
| 1 | Шапка | 🟢 неизменный (меняются только дата/время/место) | Название бренда с ✨ по краям · дата · время · локация |
| 2 | Тема | 🟡 **меняется** | Поэтическое раскрытие темы вечера — 4–6 коротких строф |
| 3 | «At this workshop we will» / «На этом воркшопе мы:» | 🟡 **меняется** | 4 буллета с em-dash — конкретно, что будем делать, привязано к теме |
| 4 | «What Awaits You?» / «Что вас ждёт?» + регистрация | 🟢 **неизменный** | 8 буллетов с 🫶 · participation details · регистрация · ссылка на FB |

**Правило:** зелёные блоки не переписываю без прямого указания. Только жёлтые.

## Инструкция для будущих анонсов

Когда Виктория говорит «сделай анонс на такую-то тему, дата такая-то, время такое-то»:

1. **Блок 1 (шапка)** — оставляю форму `✨Authentic Tantra: [Название темы]✨` и `Аутентичная Тантра: [Название темы]`. Подставляю дату, время, локацию.
2. **Блок 2 (тема)** — пишу поэтический текст в брендовом голосе, раскрывающий тему. Ориентируюсь на ритм эталона: короткие строки, повторы, разворот в середине, обещание в финале.
3. **Блок 3 (что будем делать)** — 4 буллета с em-dash, каждый обещает конкретное действие/переживание, связанное с темой. Не общие фразы — конкретные глаголы.
4. **Блок 4 (что вас ждёт + регистрация)** — копирую дословно из эталона. Не переписываю.

**Правило параллельности:** и EN, и RU версии — всегда обе, в одном сообщении, идентичной структуры, идентичного смысла (не подстрочник, а поэтический перенос).

## Дополнительный блок 5 · Скрипт видео-кружочка для Telegram (1 минута)

Кроме текстового анонса, каждый воркшоп сопровождается коротким видео-кружочком в Telegram — Виктория записывает его лично, продолжительность до 60 секунд. Это личное приглашение, не пересказ анонса.

**Структура скрипта (одинаковая для каждого воркшопа):**

1. **Хук (5–10 сек)** — назвать чувство/ситуацию, которая узнаётся телесно. Не про тему абстрактно — про то, что зритель сам знает.
2. **Разворот (25–35 сек)** — показать, что за этим стоит. Короткие фразы, дыхание. Опора на тело, не концепт.
3. **Момент узнавания (5 сек)** — «Знакомо?» / «Does this feel familiar?» — прямой контакт со зрителем.
4. **Приглашение (10–15 сек)** — тема, дата, время, место, регистрация. Практично, без лишнего.
5. **Тёплое завершение (3–5 сек)** — «Буду ждать вас» / «I'll be waiting for you». Взгляд, лёгкая пауза, конец.

**Правила:**
- Длина: 100–130 слов (в русском — 100–115). Читается спокойно за 55–60 секунд.
- Пишется под живую речь: короткие фразы, паузы, без сложных придаточных.
- Без восклицаний, без «сегодня же», без «последние места».
- Всегда EN + RU параллельно.
- Стилистика — тише, чем письменный анонс. В видео Виктория говорит от себя, глазами в камеру. Приглашение — не убеждение.

**Правило голоса:** соблюдать общие бренд-правила из `/brand/tone_of_voice.md` — короткие строки, отсутствие давления, тело как язык, без «раскрой сексуальность», без манипуляции. Восклицания и ✨ 🫶 в этом шаблоне допустимы как исключение, потому что это утверждённый формат для этого продукта (тантрические встречи), а не для сайта или общих постов.

**Правило переносов (важно):** НЕ делать перенос строки после каждой фразы. Перенос — только между смысловыми абзацами. Между абзацами оставлять ОДНУ пустую строку. Между блоком темы и списком «На этом воркшопе мы:» — тоже пустая строка. Внутри одного смыслового куска (например: «Мы начинаем играть роль, угождать, контролировать. Теряем своё дыхание. Теряем свои края.») — всё идёт сплошным абзацем без переносов.

**Правило форматирования для Telegram / соцсетей (утверждено):**
- Заголовок с ✨ — **жирный**
- Строка с датой/временем/местом — **жирная**
- Ключевые короткие фразы-опоры внутри текста темы (например «Тантра помнит.» / «Tantra remembers.») — вынесены в отдельный **жирный** абзац
- «At this workshop we will:» / «На этом воркшопе мы:» — **жирный** заголовок, сразу под ним буллеты (без пустой строки после заголовка)
- Буллеты «На этом воркшопе мы:» идут плотно, без пустых строк между ними
- «What Awaits You?» / «Что вас ждёт?» — **жирный** заголовок, сразу под ним буллеты (без пустой строки после заголовка)
- Буллеты «Что вас ждёт?» идут плотно, без пустых строк между ними (в отличие от исходного эталона, где были пустые строки — в Telegram-формате их убираем)
- Пустая строка — только между разными смысловыми блоками
